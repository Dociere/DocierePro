# DocierePro

Dociere is an offline-first desktop application designed for academic and technical writing, integrating LaTeX precision with modern visual editing. It features synchronized editors, real-time offline data management, comprehensive versioning, and Zotero-compatible citation support. Built on Electron for cross-platform compatibility, Docière enables seamless document creation catering to researchers and students alike.
