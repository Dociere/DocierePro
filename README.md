## Docière Pro

Docière Pro is an offline-first desktop application designed for academic and technical writing, integrating LaTeX precision with modern visual editing. It features synchronized editors, real-time offline data management, comprehensive versioning, and Zotero-compatible citation support. Built on Electron for cross-platform compatibility, Docière enables seamless document creation catering to researchers and students alike.

### Current Version: v0.1 (Beta)

<hr>

### Key Features

- **Equation Generation**: Create Equations hassle free with built-in equation generator that generates corresponsing LaTeX syntax.
- **Citation Manager**: Zotero like citation Manager which reliably stores the data and has the ability to produce the citation in various formats.
- **Unlimited Collaborative Editing**: Now an entire team can collaborate on a project in real time.
- **AI Chat mode**: With built-in AI Chat mode you can now overcome writers block with ease.
- **Sections View**: A simplified view which abstract ths complexities and length of the LaTeX project by only displaying relevant sections and its contents.
